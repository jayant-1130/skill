# SkillSwap — Learn by Teaching

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layouts
- `script.js` — navigation and interactive prototype behavior

## Run
Open `index.html` in your browser, or open the folder in VS Code and use Live Server.

This is a front-end prototype with sample data. Changes are held in browser memory and reset on refresh; no backend or database is connected yet.
